What this experiment proves—and what remains approximate

The tile planes are real DOM elements animated with the Web Animations API. Artwork can be disabled to inspect geometry. The middle panel reproduces the current forward-exit equations on the reference layout; it is not a live rendering of the React component.

Timings and angles in the reconstruction are estimates from the captured frames, not recovered original animation constants. The source contains motion blur and unevenly spaced frames. CSS transforms do not recreate that recorded blur automatically. The app content here is a schematic reconstruction; the original app is Office, whose panorama entrance is app-specific.

No selected tile can be identified confidently in this recording. We should not invent a selected-tile zoom based on this clip. No automatic looping or playback; use the controls to inspect motion.

Browser note: Chromium and Firefox are visually closer. WebKit needed projection on each tile instead of an ancestor; some projected extents still differ. The control checks pass, but cross-engine visual parity remains open.
